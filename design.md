# 炸弹乱斗 (Bomb Brawl)

What the person asked for: "直接复刻一个这样的游戏" — a Bomb It / Crazy Arcade (泡泡堂/炸弹人) style
top-down grid arcade game, built from the asset pack made in this project (bomber-assets/).

- Kind: classic grid bomber, one player against computer bots in one arena, last one standing wins.
- Measure: Bomb It / Crazy Arcade / Bomberman: cross-shaped blasts, chain reactions, destructible
  crates, power-ups dropped from crates (speed sneaker, blast-range potion, extra bomb).
- Look: glossy vinyl-toy / blind-box chibi, 45° top-down camera, bright saturated colors (the
  asset pack's key art). No static VFX meshes in models; blasts are drawn procedurally in code.
- Language: Chinese UI.
- Defaults taken (not asked): 1 player vs 3 bots, 15×13 arena, 3-minute round, a time-out is a draw.
